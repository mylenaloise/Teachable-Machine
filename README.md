# Teachable-Machine # 

Descrição do Projeto:
Meu projeto foi criado com o objetivo de identificar em tempo real, através da webcam, se uma pessoa está utilizando óculos ou não.

Origem dos Dados:
Fonte dos dados: Imagens próprias realizadas diretamente da minha webcam. Coletei mais de 150 capturas de imagem para cada uma das classes, alterando o ângulo do meu rosto e a iluminação.

Link do Projeto:
